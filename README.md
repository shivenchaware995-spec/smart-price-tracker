# Smart Price Tracker

A Python-based price tracking application that stores products,
tracks target prices, and generates price-drop alerts.

## Features

- Add products
- Store product information
- Set target price
- Compare current price with target price
- Price drop alert
- SQLite database
- Simple command-line interface

## Technologies

- Python
- Requests
- BeautifulSoup
- SQLite
- Schedule
